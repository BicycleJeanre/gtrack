# GTrack user guide

GTrack helps you plan workouts, follow multi-week programs and record each set from a phone or computer. Tap the **?** in the app header at any time for the same guidance inside the app. Smaller **?** buttons explain the feature beside them.

## Train with more than one person

Use the profile button in the header to add or switch between people such as you and your partner. Each training profile has separate workouts, programs, completed history, body measurements and PRs inside the same account. The exercise library remains shared. Finish or discard an active workout before switching profiles so a session cannot be assigned to the wrong person.

## Start and resume a workout

Open **Today** to start the next workout in your current program, choose a saved workout, or start an empty session. An active workout is stored on the current device and appears in a persistent bar at the top of every screen. Tap the workout name in that bar to resume it.

You can build the session while recording it. Add, remove or reorder exercises and sets, and change the session name or rest time. Removing an item happens immediately. **Finish workout** saves completed sets to History; **Discard this session** removes the entire active draft.

## Record an exercise

Each exercise in a workout or active session has a tracking type:

| Tracking type          | Use it for                              | Units                       |
| ---------------------- | --------------------------------------- | --------------------------- |
| Weight + reps          | Loaded strength exercises               | kg or lb                    |
| Machine setting + reps | Cable stacks with unknown plate weights | numbered plates and reps    |
| Reps only              | Bodyweight or repetition-only movements | reps                        |
| Time                   | Holds, carries and intervals            | seconds or minutes          |
| Distance               | Cardio and carries                      | metres, kilometres or miles |

Enter the result and tap the tick to complete the set. Weight fields accept two decimal places, so smaller increments such as **1.25 kg** are preserved in plans, active workouts, history and progress. Tap the tick again to reopen it. GTrack saves every valid change to the device. **Last time** summarizes the most recent comparable workout, and each set shows the result from the matching previous set. For an unknown-weight cable stack, choose **Machine setting + reps** and record the numbered plate setting. It remains visible in history and previous results but does not contribute to weight volume.

When a completed set beats a saved weight, machine-setting, reps, set-total, time or distance record, GTrack marks that row with a gold medal and shows a short congratulations banner with the new result and previous best. A first-ever result establishes the baseline. Live PRs compare completed workout history in the same tracking type and unit, so kilograms and pounds are never compared as if they were equal.

Use the same unit for an exercise over time so previous results and personal records are easy to compare.

For a movement performed independently on both sides, choose **Log left and right sides separately** while adding it to a session or workout plan. Each planned set becomes a left row and a right row. Add or remove set pairs together. Previous results and live PRs compare the same side, and the automatic rest timer starts after the right-side row is completed.

## Find and add exercises

GTrack includes 969 bundled and curated exercise names that remain available offline, including the beginner prenatal stretching movements and common yoga and mobility poses. The active-session picker shows a picture for every bundled movement so you can identify a machine or exercise without knowing its name. Tap any exercise picture to open a larger preview; closing it returns you to the same list without selecting the exercise. Search by name and filter by exercise type, equipment or broad primary muscle group. Choosing a broad group such as **Back**, **Legs** or **Arms** reveals a second filter for detailed muscles. Exercises you already selected remain selected while you refine the filters, and an open picker refreshes if the shared library syncs.

You can select several picture cards before choosing **Add to session**. Each selected movement is added as a separate exercise. The search, type, equipment and muscle filters remain selected when you reopen the picker in the same active session.

If a movement is missing, choose **New exercise for the library**. Only a clear name is required. Description, exercise type, equipment, broad and detailed muscle information, and a photo are optional. GTrack compresses any photo before saving it. Custom exercise names, photos and metadata are shared between signed-in users; training profiles, workouts, programs, body measurements and history remain private.

## Add exercise notes

Every exercise in an active workout has an optional **Workout note**. Use it for a machine seat number, cable attachment, stance, technique reminder or discomfort you want to remember. The note saves on the phone when you leave the field, syncs with the completed workout and appears in History. The most recent comparable workout note also appears with the previous result next time you perform that exercise.

Choose **View form** to see available movement photos and technique cues. These are general form reminders and do not replace individual coaching.

## Use the rest timer

Completing a set starts the rest timer automatically when timed rest is enabled. Choose **No automatic rest timer** while creating a workout or editing session details to pace rests yourself. A no-rest session shows **Rest timer: Off** and completing a set does not start a countdown, chime or notification.

- **Start** restarts the timer using the session rest period.
- **+30** adds 30 seconds, or starts a 30-second timer when idle.
- **Skip** stops the current timer.
- **Enable alerts** requests notification permission.

When the timer finishes, GTrack uses a chime, vibration, an on-screen popup and a system notification where supported. On iPhone, iOS may suspend an installed web app while another app is open. If that happens, GTrack alerts you when it becomes active again. Keep sound enabled and grant notifications for the best result.

## Run guided intervals

For yoga, Pilates, stretching, mobility work or timed circuits, choose **Time** as the exercise tracking type and enable **Run as a guided interval**. Enter the duration of every timed set, the rest between sets and the rest after that exercise. These timers are optional and can be left off for any timed exercise.

When the workout starts, choose **Start intervals** on Today. GTrack counts down the work period, completes that set, counts down its set rest, and advances to the next set. After the last set it uses the exercise rest and then starts the next guided exercise. Every transition uses the same chime, vibration, popup and system notification support as the normal rest timer. **Complete now**, **Skip rest** and **Stop timer** remain available, and the current countdown stays in the persistent top bar while you browse the app. The interval state is saved on the device so returning to the installed app resumes the sequence.

## Edit a completed workout

Open **History** and choose **Edit logged workout**. You can rename the workout, correct recorded values, change an exercise to another library movement, remove exercises, add missing exercises, and choose which sets count. A newly added exercise starts with one counted weight-and-reps set that you can correct before saving. At least one valid completed set must remain.

The original workout date and program position do not change. Signed-in edits sync to other devices when GTrack is open and connected.

## Understand personal records

Open **Progress** and select an exercise. PRs use completed sets in the selected profile's saved workout history. During an active workout, the same history powers the gold live PR marker and congratulations banner. Left and right results are compared with the same side during a unilateral workout.

- **Highest weight** is the heaviest completed set.
- **Highest reps** is the most repetitions in one completed set.
- **Estimated 1RM** estimates a one-repetition maximum from weight and reps using the Epley formula. High-repetition sets above 12 reps use the recorded weight because estimates become unreliable.
- **Best set total** is weight multiplied by reps for one set.
- **Best workout total** combines all completed sets of that exercise in one workout.

Machine-setting exercises show the highest numbered setting and highest reps without treating the setting as weight. Reps-only, timed and distance exercises show the best set and best workout total in their own unit.

The muscle workload map assigns completed sets from the last 30 days to each exercise's primary muscle. A stronger colour represents more completed sets. It reports training workload rather than fatigue, recovery or muscle growth.

## Track body measurements

Open **Progress → Body** to add any combination of body weight, body-fat percentage, waist, chest, upper-arm and thigh measurements. You can edit an existing entry if a value was entered incorrectly. Measurements belong to the selected training profile. Signed-in body records remain private, sync between your devices and are included in backups.

## Use the calculators

Open **Progress → Calculators**.

- **Plate calculator** subtracts the bar from the desired total and shows the standard plates required on each side. It reports the closest achievable load when the total cannot be made exactly.
- **Warm-up calculator** creates four progressively heavier preparation sets from the working weight and reps. Change the rounding increment to match the available plates or dumbbells.

Calculator results are suggestions. Adjust or skip sets based on the movement, equipment, experience and readiness that day.

## Follow or create a program

Open **Programs** to choose a suggested program or create your own. **Today** then shows the next session, week and phase automatically.

You can review weights before starting or start the next session directly. When finishing, choose whether the workout counts for program progress. Custom programs can be edited, duplicated, paused or removed without deleting completed history.

## Saving, sync and offline use

The active workout stays on the current device. Signed-in training profiles, workouts, programs, body measurements and completed history sync while the app is open and connected. Tap the save/sync status near the top of a screen to open Account and see more detail. Backups contain every profile and all of their records.

GTrack can launch offline after the production app has completed its first online load. Use **Account → Request persistent storage** where available, and keep an exported backup. Browser storage can still be cleared by the device or user.
