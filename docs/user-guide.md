# GTrack user guide

GTrack helps you plan workouts, follow multi-week programs and record each set from a phone or computer. Tap the **?** in the app header at any time for the same guidance inside the app. Smaller **?** buttons explain the feature beside them.

## Start and resume a workout

Open **Today** to start the next workout in your current program, choose a saved workout, or start an empty session. An active workout is stored on the current device and appears in a persistent bar at the top of every screen. Tap the workout name in that bar to resume it.

You can build the session while recording it. Add, remove or reorder exercises and sets, and change the session name or rest time. Removing an item happens immediately. **Finish workout** saves completed sets to History; **Discard this session** removes the entire active draft.

## Record an exercise

Each exercise in a workout or active session has a tracking type:

| Tracking type | Use it for                              | Units                       |
| ------------- | --------------------------------------- | --------------------------- |
| Weight + reps | Loaded strength exercises               | kg or lb                    |
| Reps only     | Bodyweight or repetition-only movements | reps                        |
| Time          | Holds, carries and intervals            | seconds or minutes          |
| Distance      | Cardio and carries                      | metres, kilometres or miles |

Enter the result and tap the tick to complete the set. Tap the tick again to reopen it. GTrack saves every valid change to the device and shows the most recent completed result for that exercise under **Last time**.

Use the same unit for an exercise over time so previous results and personal records are easy to compare.

## Find and add exercises

GTrack includes 876 exercises that remain available offline. Use the search box in the exercise guide, workout builder or active-session picker. Filter by equipment and primary muscle when the name is unknown or the list is too broad. While recording, you can select several exercises before choosing **Add to session**.

If a movement is missing, choose **New exercise for the library** and enter a clear name, description, equipment and primary muscle. Custom exercise names and metadata are shared between signed-in users; workouts, programs, body measurements and training history remain private.

Choose **View form** to see available movement photos and technique cues. These are general form reminders and do not replace individual coaching.

## Use the rest timer

Completing a set starts the rest timer automatically. The timer remains visible in the top bar when you move to another GTrack screen.

- **Start** restarts the timer using the session rest period.
- **+30** adds 30 seconds, or starts a 30-second timer when idle.
- **Skip** stops the current timer.
- **Enable alerts** requests notification permission.

When the timer finishes, GTrack uses a chime, vibration, an on-screen popup and a system notification where supported. On iPhone, iOS may suspend an installed web app while another app is open. If that happens, GTrack alerts you when it becomes active again. Keep sound enabled and grant notifications for the best result.

## Edit a completed workout

Open **History** and choose **Edit logged workout**. You can rename the workout, correct recorded values, and choose which sets count. At least one valid completed set must remain.

The original workout date and program position do not change. Signed-in edits sync to other devices when GTrack is open and connected.

## Understand personal records

Open **Progress** and select an exercise. PRs use completed sets in saved workout history.

- **Highest weight** is the heaviest completed set.
- **Highest reps** is the most repetitions in one completed set.
- **Estimated 1RM** estimates a one-repetition maximum from weight and reps using the Epley formula. High-repetition sets above 12 reps use the recorded weight because estimates become unreliable.
- **Best set total** is weight multiplied by reps for one set.
- **Best workout total** combines all completed sets of that exercise in one workout.

Reps-only, timed and distance exercises show the best set and best workout total in their own unit.

The muscle workload map assigns completed sets from the last 30 days to each exercise's primary muscle. A stronger colour represents more completed sets. It reports training workload rather than fatigue, recovery or muscle growth.

## Track body measurements

Open **Progress → Body** to add any combination of body weight, body-fat percentage, waist, chest, upper-arm and thigh measurements. You can edit an existing entry if a value was entered incorrectly. Signed-in body records remain private, sync between your devices and are included in backups.

## Use the calculators

Open **Progress → Calculators**.

- **Plate calculator** subtracts the bar from the desired total and shows the standard plates required on each side. It reports the closest achievable load when the total cannot be made exactly.
- **Warm-up calculator** creates four progressively heavier preparation sets from the working weight and reps. Change the rounding increment to match the available plates or dumbbells.

Calculator results are suggestions. Adjust or skip sets based on the movement, equipment, experience and readiness that day.

## Follow or create a program

Open **Programs** to choose a suggested program or create your own. **Today** then shows the next session, week and phase automatically.

You can review weights before starting or start the next session directly. When finishing, choose whether the workout counts for program progress. Custom programs can be edited, duplicated, paused or removed without deleting completed history.

## Saving, sync and offline use

The active workout stays on the current device. Signed-in workouts, programs, body measurements and completed history sync while the app is open and connected. Tap the save/sync status near the top of a screen to open Account and see more detail.

GTrack can launch offline after the production app has completed its first online load. Use **Account → Request persistent storage** where available, and keep an exported backup. Browser storage can still be cleared by the device or user.
