# Changelog

## 0.1.0 — 2026-09-14

Initial mobile gym-training app.

- Workout plans with individual reps and weights for each set.
- Reusable exercise library with names and descriptions.
- Durable offline logging, history, progress and backup export/import.
- Firebase accounts, shared exercises and private training records.
- Installable PWA with versioned caching and safe updates.
- Automated browser, data-model, security-rule and sync checks.

Firebase rules are deployed to `YOUR_FIREBASE_PROJECT`. The GitHub Pages build is prepared; publishing is blocked by the current GitHub plan for this private repository.
